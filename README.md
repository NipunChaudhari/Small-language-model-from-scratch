# Small Language Model From Scratch

## 📌 Project Overview

This project documents my learning and implementation journey
towards understanding and building a Small Language Model (SLM)
from the fundamentals.

The goal is to understand the internal working of language models
rather than directly using a pretrained model as a black box.

---

## 🎯 Objectives

- Understand the fundamentals of Language Models
- Understand tokenization and vocabulary
- Learn PyTorch fundamentals
- Understand embeddings
- Understand neural network training
- Understand self-attention
- Understand Transformer architecture
- Build a small language model from scratch
- Train and evaluate the model
- Explore model optimization and deployment

---

## 🧠 Learning Approach

The project follows:

Learning
   ↓
Implementation
   ↓
Experiment
   ↓
Evaluation
   ↓
Documentation

Each major concept will be documented with theory,
code, experiments and observations.
